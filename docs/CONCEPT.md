# Tomk Engine Concept

Tomk Engine ka base idea ek custom 3D game engine banana hai jisme editor, renderer, rigging, FPS gameplay aur custom scripting language ek saath kaam karein.

## Main Systems

- 3D renderer: viewport, camera, lighting, materials, shaders.
- Editor: hierarchy, inspector, asset browser, gizmos, scene editing.
- Rigging: bones, skeleton, skinning, animation clips.
- FPS tools: player controller, camera, weapons, interaction, input.
- Scripting: Tomk Script language with C#-like structure.
- Runtime: final game/project ko run karne ka launcher.

## Development Direction

Start simple: ek window, ek cube, camera movement, aur scene file loader. Uske baad editor tools aur scripting bridge add karna.
